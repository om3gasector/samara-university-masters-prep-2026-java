# Легковесное локальное веб-приложение для интервального повторения знаний из Markdown-файлов.

Читает только `.md` из папки "Знания" в корне хранилища (родительская папка от `learn-app`). Карточки: заголовок — «вопрос», текст до следующего заголовка того же или более высокого уровня — «ответ». Ссылки `[[...]]` на обороте показываются без скобок.

## Запуск

1. Открой терминал в папке `learn-app`.
2. Выполни
```bash
python server.py
```
3. В браузере: http://127.0.0.1:8765

Если по `localhost:8765` страница не грузится, оставь **127.0.0.1** - на части систем `localhost` уходит на IPv6, а сервер слушает только IPv4.

### Навык и подкаталог

- **Навык** - это прямая подпапка внутри `основного хранилища` (например `Английский`, `Немецкий` или любая изучаемая область). Список строится автоматически по именам папок.
- **Подкаталог** — необязательно: первый уровень внутри выбранного навыка, где есть хотя бы одна `.md` заметка (в этой папке или глубже). Значение **«Весь навык»** включает все заметки навыка.

Выбранные навык и подкаталог сохраняются в браузере (`localStorage`).

Ответ на карточке рендерится как **Markdown** через скрипты с CDN (`marked` + `DOMPurify` + `highlight.js`). Нужен интернет при первой загрузке страницы. 
**Для корректной подсветки кода в ответах обязательно указывайте язык программирования строчными буквами после тройных кавычек** (например, ```java```, ```python```, ```sql```).
### Структура заметок

```markdown
#### 1.1 Основной вопрос   // 4 уроверь заголовка
##### 1.1-1 Подвопрос      // 5 уроверь заголовка
```
### Отображение синтаксиса кода

Приложение автоматически подсвечивает программный код внутри ответов. Чтобы цвета отображались корректно, **обязательно указывайте язык** после открывающих тройных кавычек. Идентификаторы должны быть написаны **строчными буквами**.

**Правильное оформление:**
```java
public class Task1 { ... }
```
Полный список поддерживаемых языков доступен в [документации highlight.js](https://highlightjs.org/languages/)

**Популярные идентификаторы:**
- `java` — Java
- `python` / `py` — Python
- `javascript` / `js` — JavaScript
- `sql` — SQL
